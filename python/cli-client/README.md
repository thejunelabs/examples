# Python CLI Client

This project is a basic command-line interface (CLI) client application built with Python. It serves as an example for setting up and running a simple Python application.

## Setup

1.  **Navigate to the project directory**:
    ```bash
    cd python/cli-client
    ```

2.  **Create a virtual environment** (recommended):
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Environment Variables**:
    If the application requires environment variables, copy the `.env.example` file to `.env` and update the values accordingly:
    ```bash
    cp .env.example .env
    ```

## Usage

To run the CLI application, execute the `main.py` script:

```bash
python main.py
```

Follow any on-screen prompts or refer to the `main.py` file for specific command-line arguments.
